## [2026.09] - 2026-09-16

- Maintenance review of ai-operating-system-guide — a public, beginner-oriented guide to running a one-person digital agency on top of Claude Code.
- Status: a documentation repo of three files — a single self-contained `index.html` (no dependencies, no build step, no tracking), the 61-page `AI-Operating-System-Guide.pdf` generated from it, and the README. Published via GitHub Pages at https://waseemnasir2k26.github.io/ai-operating-system-guide/ and covering parts 0-13, from installing the terminal through memory, skills, subagents, hooks, MCP, quality gates and a 7-day plan.
- Reviewed September 2026: README Status section added and a CHANGELOG created; the repo is versioned as v2026.09. The guide's HTML and PDF were not regenerated or edited.
- Known gaps: no LICENSE file, so reuse terms for the guide are undefined; no CHANGELOG before this release; the PDF is a committed build artifact that must be regenerated by hand whenever `index.html` changes, with nothing enforcing that the two stay in sync; content reflects the August 2026 v2 rebuild and has not been re-checked against current Claude Code behaviour.
